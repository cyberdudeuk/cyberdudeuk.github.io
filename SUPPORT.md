# Getting help

- About the launchpad, or if you are not sure where to go: the [contact form](https://github.com/cyberdudeuk/cyberdudeuk.github.io/issues/new?template=contact.yml)
- A card is wrong or a project is missing: the [listing form](https://github.com/cyberdudeuk/cyberdudeuk.github.io/issues/new?template=listing.yml)
- About one project: that project's own contact form, linked from its site
- Security problems: private reporting from the **Security** tab, never a public issue
