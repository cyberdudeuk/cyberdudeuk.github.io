One home for my open work, and where else to find it

My open projects now have one home, Public Good Works. This note lists where else they appear, and which copy to trust.

My open projects on data and AI for UK public services, and my personal public-good projects, now have one home: Public Good Works, at cyberdudeuk.github.io. This note lists where else they appear, and which copy to trust.

Where to find the work

  • The launchpad lists every public project with its status, licence and live site.
  • The code is on GitHub, and each repository is preserved in the Software Heritage archive.
  • Most projects' releases have a citable DOI through Zenodo, linked to my ORCID record.
  • Notes like this one are written here first and copied to DEV, with a link back to this page as the original.
  • LinkedIn carries short updates.

Which copy to trust

The launchpad is the source. It links to each of my profiles and each profile links back to it, so you can check they belong to the same person. If a copy elsewhere differs, the launchpad is the one kept current.

Getting in touch

Use the contact form linked from the launchpad, or the one on each project's own site. There is no email route.

These are personal projects and personal views. None is an official government service, policy or endorsement unless the project says so.
