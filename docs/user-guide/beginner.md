# Beginner guide

1. Open [the launchpad](https://cyberdudeuk.github.io/).
2. Look at **Choose your way in**: the Beginner suggestions work in any browser, with no account.
3. Each card says what the project does, who it is for and its status. Select **Open the site**.

*Prototype* means not finished. *Proposed, not endorsed* means put forward for review, not agreed. None of these is an
official government service unless the project says so.
