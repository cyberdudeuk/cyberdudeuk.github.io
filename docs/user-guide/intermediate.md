# Intermediate guide

- **Filter** by area (for example *Data management and quality*) and by level, then sort by most recently updated.
- **Before you rely on a project at work**, read its README and status, and check when it was last updated (on its card).
- **Wrong or missing?** Use the [listing form](https://github.com/cyberdudeuk/cyberdudeuk.github.io/issues/new?template=listing.yml).
