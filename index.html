About

Who makes these

Projects from the cyberdudeuk GitHub account, most of them about data and AI in UK public services, plus some personal work. Each project is built in the open, checked automatically before it is published, and says plainly what it is and is not.

How to read this page

  • Status is as each project states it. Prototype and proposed mean not finished and not official.
  • Summaries are written from each project's own README.
  • None of these is an official government service, policy or endorsement unless the project says so.
  • Forks and private repositories are not listed.

Contact

Use the contact form. It opens a GitHub issue, which is public, so do not include personal data. There is no email route. For a problem with one project, use that project's own contact form, linked from its site.

Disclaimer. Made in a personal capacity. These projects are not official government services or policy, and listing a project does not mean any organisation endorses it.

Transparency. This page is built from projects.json by tools/build.py and checked before it is published. Written with help from Claude (Anthropic). No cookies, analytics or third-party requests.

Licences. This launchpad: code MIT, text OGL v3.0. Each project has its own licence, shown on its card.
